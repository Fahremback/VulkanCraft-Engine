# Política de segurança

## Relato de vulnerabilidades

Não abra uma issue pública para falhas que possam expor máquinas, credenciais,
arquivos locais ou conteúdo de projetos.

Use **Security > Report a vulnerability** neste repositório para enviar o relato
privadamente. Inclua a versão ou commit afetado, impacto, forma de reprodução e uma
sugestão de mitigação quando possível.

Não inclua tokens, dados pessoais, saves privados ou assets licenciados no relato.

## Escopo atual

Somente a branch `main` recebe correções. Como a engine ainda está em desenvolvimento
ativo, não há garantia de compatibilidade para snapshots antigos.
